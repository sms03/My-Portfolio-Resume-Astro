## Special Components

<div className="prose prose-slate dark:prose-invert mb-8">
  <h3>3D Circular Gallery</h3>
  <p>Custom React component utilizing OGL (OpenGL) for WebGL-based 3D image galleries with smooth transitions and responsive design. Features include:</p>
  <ul>
    <li>Hardware-accelerated WebGL rendering</li>
    <li>Responsive breakpoint handling</li>
    <li>Custom shader programs for visual effects</li>
    <li>Touch and mouse interaction support</li>
  </ul>

  <h3>Audio Integration</h3>
  <p>Custom audio player component with:</p>
  <ul>
    <li>Multiple audio format support (WAV, MP3, OGG)</li>
    <li>Play/pause state management</li>
    <li>Accessible controls and ARIA labels</li>
  </ul>

  <h3>Theme System</h3>
  <p>Comprehensive dark/light mode implementation featuring:</p>
  <ul>
    <li>System preference detection</li>
    <li>Persistent theme storage</li>
    <li>Smooth transitions between modes</li>
  </ul>
</div>
